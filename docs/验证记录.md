# 2026-10-23 动作、收尾与旧版射灯修订

版本仍为 1.0.0。本节记录这次修订，后面保留之前版本的验证背景。

- 问题复现：原版动作逻辑在 6720 个舞动采样中，6498 个左右手侧采样存在明显后摆；最差切换的肘部单帧位移约 44.9 厘米，关节转动接近 180°。原因包括左右手节奏分离、手肘参考向量混用了平面法线与弯曲方向，以及切换时突然改用另一条求解路径。
- 修正后改为同一真人片段的双臂节奏，并按人体关节活动范围重定向上臂和前臂；上臂自然下垂，避免把手腕硬拉向一个位置造成外张。手肘弯曲方向连续传递，接触修正的重复求解不能在同一帧再跳一次。
- 26.2 的 6720 个舞动姿态采样没有触发后摆条件；覆盖 7 个变体及所有不同姿态之间的 84 条切换，最大 60fps 手腕单帧位移约 2.92 厘米、肘部约 2.69 厘米，最大局部关节单帧转动约 0.116 弧度。检查条件、源码及完整输出保存在源码包 validation 中。
- 6720 个握麦姿态检查通过，腕部位置最大偏差约 6.2e-7 模型单位，朝向最大偏差约 0.00155 弧度，独立手指仍在正确铰链上转动。单话筒不会进入打碟姿态。
- 接触与连续性检查通过：静态打碟没有检测到台面穿透；准备动作连续，声音前不开始打碟；走路支撑脚和离开表演后的走路仍通过检查。60fps 连续舞动采样的最大手腕位移约 0.0062、相邻位移差约 0.0013 模型单位。
- Forge 1.20.1 在 LevelRenderer 的真实世界参数中复制投影与视图矩阵，并在世界绘制完成后复制深度。修正原先读取全局临时矩阵，可能拿到其他绘制阶段状态的问题。也处理了 packed depth/stencil 格式，并在自己的绘制期间关闭、随后恢复模板测试。
- Forge 1.20.1 最终生产 reobf JAR 在 Oculus 1.8.0 + Embeddium 0.3.31 + SEUS Renewed 1.0.1 中完成实机检查：双手舞动、转回打碟、原版双色刷怪蛋、独立声源、灯光雾气、拆除设备渐隐和保存退出通过。左右移动相机的两张截图已人工检查，光柱随灯具的世界位置显示。批量提交计数为 439149384 个顶点，证明优化路径已实际启用。
- Fabric 1.21.1 最终生产 remap JAR 在 Iris 1.8.8 + Sodium 0.6.13 + SEUS Renewed 1.0.1 中通过相同开场、舞动、切换、灯光渐隐与多声源检查，腕部目标偏差约 9.1e-6 模型单位。
- Forge 1.20.1 不安装 Oculus、Embeddium 和光影的独立实机检查也通过，射灯左右视角定位、设备拆除渐隐及保存退出正常。
- 两个旧版本与 26.2 的动作采样数和通过条件一致，结果可见各自的 gesture 日志。
- 旧版优化：模型骨骼列表只建立一次；Forge 的原生提交适配 Embeddium 的 VertexFormatDescription。实机用计数器确认批量提交在工作，没有绕过 Oculus 的顶点扩展接口。此项不等同于一个固定 FPS 提升百分比。
