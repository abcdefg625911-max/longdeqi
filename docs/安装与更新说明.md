# 隆德齐 1.0.0 正式版

本模组由 AI 辅助制作。三个游戏版本是独立构建和发布的版本，各自维护版本号。每个 GitHub Release 只放一个游戏版本和加载器对应的 JAR，以及该版本匹配的源码 ZIP。标签分别使用 `fabric-26.2-v1.0.0`、`fabric-1.21.1-v1.0.0`、`forge-1.20.1-v1.0.0`。请选择与实例完全匹配的 Release 文件；多人游戏的服务端和客户端都需要安装相同版本。

## 本次手臂与话筒图标修订（2026-10-23）

- 恢复舞动上臂的前伸、外展变化，重新映射前臂弯曲，避免上一轮幅度限制导致上臂贴身、小臂接近不动。
- 保留肘部连续转向和手腕限制；手势在台面附近提前抬高，接触修正连续释放，避免切换或经过台沿时突然跳动。
- 话筒物品模型的每个面都明确指定有效贴图坐标，修正旧版采到相邻绿色图集的问题。
- 话筒 GUI 缩放从 0.78 调为 0.58，重新居中；放置后的话筒尺寸不变。三个版本同步更新。

## 上一轮动作与灯光修订

- 三个版本同步修正舞动手臂：使用同一真人动作片段的双臂节奏，限制上臂后摆和过度外张，让前臂承担主要手势。
- 统一各姿势的手肘参考方向，加入连续的肘部转向与平滑收尾，修正舞动转打碟、握麦时的翻转和抽动。
- Forge 1.20.1 射灯直接使用世界渲染时的真实视图与投影矩阵，修正光柱跟随视角偏移、仅在特定位置可见的问题；深度复制不再依赖是否渲染手持物。
- 旧版本缓存模型骨骼列表；Forge 支持 Embeddium 的顶点格式描述接口，启用批量网格提交并保留 Oculus 的扩展顶点处理。

## 原有设置

- `/longdeqi hall` 不再发出自定义查找说明，成功时使用原版传送消息样式。开启作弊或拥有 OP 权限后执行；`/longdeqi hall cancel` 取消正在进行的查找。
- 野外舞厅的候选网格改为 32×32 区块、间隔 16 区块、候选频率 100%。与上一版 40×40 / 80% 相比，候选密度约翻倍。最终建筑仍需通过群系、地形和村庄避让检查，因此不是每块区域都会出现。
- 村庄中心仍保持约 10% 的舞厅选择概率。外观仅使用橡木或云杉木及对应木板、白色陶瓦组合，按原先的合适群系生成。停用超平坦密集展示。
- Forge 1.20.1 和 Fabric 1.21.1 保留现有模型、手指、动画、固定握麦开场、交易、合成、村民观众、通透效果、独立声音叠加、射灯和雾气渐变。刷怪蛋使用旧版原版双色样式。
- 修正旧版 JOML 旋转角度转换的误差，避免移植后手部和麦克风重新错位。

只有话筒时，固定握麦开场持续随机 10–30 秒，从实际开唱开始计时；有混音台时固定双手打碟开场。歌曲仍为用户提供的《雨爱（司冯版）》。

生成频率只影响新生成的区块，已有舞厅不会自动移动、重建或删除。也可使用原版 `/locate structure #longdeqi:concert_halls` 查看野外舞厅坐标。

光影测试范围和实测结果见“验证记录.md”。本次没有修改用户原游戏实例、存档或光影文件。
