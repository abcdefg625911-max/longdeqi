# 隆德齐 Minecraft 模组

> 本模组由 AI 辅助制作。

为 Minecraft Java 制作的演出模组，包含三个独立版本。三个版本分别构建和发布，版本号可以独立更新。下载时请按游戏版本和加载器选择对应 Release；每个游戏实例只放入一份匹配的 JAR。

| Minecraft | 加载器 | Java | 依赖 | Release 标签 |
| --- | --- | --- | --- | --- |
| 26.2 | Fabric Loader 0.19.5 | 25 | Fabric API 0.161.0+26.2 | `fabric-26.2-v1.0.0` |
| 1.21.1 | Fabric Loader 0.16.14 或更新版 | 21 | Fabric API 0.116.17+1.21.1 | `fabric-1.21.1-v1.0.0` |
| 1.20.1 | Forge 47.4.0 或更新版 | 17 | 实测 Forge 47.4.26 | `forge-1.20.1-v1.0.0` |

## 下载与安装

前往 [GitHub Releases](https://github.com/abcdefg625911-max/longdeqi/releases)，根据 Release 标题选择对应的 Minecraft 版本和加载器。每个 Release 只包含该版本的 JAR 与匹配的源码 ZIP；不要把不同版本的文件混用。

将所选 JAR 放入对应游戏实例的 `mods` 文件夹。多人游戏需在客户端和服务器安装相匹配的模组版本。

模组包含隆德齐、话筒、混音台、表演动作与音乐内容。详细安装说明、素材来源及验证范围见 `docs` 文件夹。

## 独立版本发布规则

三个版本各自维护发布标签和版本号。首发标签分别为：

- Fabric 26.2：`fabric-26.2-v1.0.0`
- Fabric 1.21.1：`fabric-1.21.1-v1.0.0`
- Forge 1.20.1：`forge-1.20.1-v1.0.0`

以后更新某个版本时，只更新该版本的 Release，例如 `fabric-26.2-v1.0.1`，其他版本的标签和文件不变。

本仓库不附带自定义许可证；素材的来源和权利说明见 [docs/素材来源.md](docs/素材来源.md)。
