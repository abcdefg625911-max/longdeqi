# 隆德齐 Minecraft 模组

为 Minecraft Java 制作的演出模组，包含三个独立版本。下载时请按游戏版本和加载器选择对应文件；每个游戏实例只放入一份匹配的 JAR。

| Minecraft | 加载器 | Java | 依赖 |
| --- | --- | --- | --- |
| 26.2 | Fabric Loader 0.19.5 | 25 | Fabric API 0.161.0+26.2 |
| 1.21.1 | Fabric Loader 0.16.14 或更新版 | 21 | Fabric API 0.116.17+1.21.1 |
| 1.20.1 | Forge 47.4.0 或更新版 | 17 | 实测 Forge 47.4.26 |

安装时将所选 JAR 放入对应实例的 mods 文件夹。多人游戏需在客户端和服务器安装相匹配的模组版本。

模组包含隆德齐、话筒、混音台、表演动作与音乐内容。详细安装说明、素材来源及验证范围见 docs 文件夹。
